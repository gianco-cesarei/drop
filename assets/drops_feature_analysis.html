Analisi feature per il progetto Drops — downloader audio/video

Alta priorità — impatto immediato

Audio

Tag ID3 automatici

Titolo, artista, album e copertina scritti nell'MP3 — visibili in ogni lettore musicale.

FacileAlto impatto

Download playlist

Incolla il link di una playlist YouTube e scarica tutti i brani in coda, con barra per ogni traccia.

MediaAlto impatto

Cartella di salvataggio custom

Scegli dove salvare i file (es. ~/Music) invece che scaricare dal browser ogni volta.

FacileAlto impatto
App desktop

Cronologia con ricerca

Lista persistente di tutto il scaricato, filtrabile per nome o tipo. Ora la cronologia si azzera alla chiusura.

FacileAlto impatto

Notifica macOS al termine

Notifica nativa quando il download è pronto, così non devi tenere l'occhio sulla finestra.

FacileMedio impatto

Drag & drop URL

Trascina il link dalla barra del browser direttamente nella finestra dell'app.

FacileMedio impatto

Media priorità — feature avanzate

Video

Editor clip con anteprima

Barra temporale con slider visuale per scegliere inizio/fine invece di digitare i secondi.

MediaMedio impatto

Converti MP4 → MP3 da file locale

Trascina un file MP4 già scaricato e Drops estrae l'audio senza rifare il download.

FacileMedio impatto
Configurazione

Preferenze persistenti

Salva qualità di default, cartella di salvataggio, formato preferito — non devi riselezionare ogni volta.

FacileMedio impatto

Auto-aggiornamento yt-dlp

Aggiorna yt-dlp in background all'avvio — YouTube cambia spesso le API e versioni vecchie smettono di funzionare.

FacileAlto impatto

Bassa priorità — futuro

Deploy pubblico (Render + Netlify)

L'infrastruttura è già pronta. Basta configurare le variabili d'ambiente e deployare.

Media

Supporto altri siti

yt-dlp supporta già Vimeo, TikTok, Instagram, Twitch — basta allargare ALLOWED_DOMAINS.

Facile

Coda download multipli

Aggiunge più URL contemporaneamente e li gestisce in parallelo con progress per ognuno.
